Palette source/license is embedded in each `assets/palettes/json/*.json` and in
`assets/palettes/all-palettes.json`. The reduced pack bundles only one generated
vignette overlay; the full local edition adds Poly Haven CC0 textures and
procedural assets.

This directory is a reference, not a substitute for reading the upstream
license. When in doubt, check the source link.
