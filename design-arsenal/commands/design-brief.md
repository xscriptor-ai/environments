Create a design brief before any production starts. Do not generate images yet.

Collect or infer, and explicitly mark assumptions:

1. Intent: one sentence describing the place/mood the piece should create.
2. Deliverables: desktop 16:9, ultrawide, mobile 9:20, square, light/dark,
   print/web, quantity.
3. Source: licensed images, fonts, textures, screenshots, existing brand.
4. Constraints: resolution, file size, platform, icon/dock/panel zones, text.
5. Direction: 6-10 references with the mechanism that matters (not just links).
6. Palette: choose or extract; list roles and contrast targets.
7. Type: display/text/mono pairing and scale.
8. Composition: primary focal point, field strategy, negative space, series rule.
9. Pipeline: exact commands, extension method, upscale, grain/vignette values.
10. QA: checklist and acceptance criteria.
11. Licensing: source, license, attribution obligations.

Output the brief as Markdown in the project folder, plus a `series.md` skeleton
and a manifest skeleton. Ask only questions that change the outcome.
