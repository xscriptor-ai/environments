# Learning Path

## Beginner

1. **Three.js Journey** (Bruno Simon) — the most complete paid course, updated with R3F.
2. **Discover Three.js** — free, structured, practical.
3. **Three.js Manual** — official, covers fundamentals.
4. **Three.js Examples** — read the source of the effect you want.
5. Build: a rotating product, a scroll landing page, a small configurator.

## Intermediate

1. **The Book of Shaders** — fragment shader fundamentals.
2. **WebGL Fundamentals** — how the pipeline really works.
3. **Learn OpenGL** — lighting, shadows, PBR, post-processing (C++ but transferable).
4. **Scratchapixel** — rendering math and ray tracing.
5. **R3F docs + Drei** — declarative scene composition.
6. Build: a custom shader material, a post-processed scene, a physics toy.

## Advanced

1. **TSL specification** — node materials, compute, RenderPipeline.
2. **WebGPU Fundamentals** and best practices.
3. **GPU Gems / SIGGRAPH talks** — techniques, not Three.js-specific.
4. **three.js source** — read addons and renderer internals.
5. **Path tracing / Gaussian splatting papers** — advanced rendering.
6. Build: a GPGPU particle system, a compute simulation, a custom render pipeline.

## Habits

- Read the source of examples, not only tutorials.
- Build small, finish projects.
- Profile early; do not guess.
- Keep a personal snippet library.
- Write down what broke and why.
- Follow the Migration Guide on every upgrade.
