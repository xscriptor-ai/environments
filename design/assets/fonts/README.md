# Font manifest

The reduced pack does not bundle TTF binaries (4.7 MB in the full arsenal). These 12 families are SIL Open Font License 1.1; download from Google Fonts:

| Family | Use | Upstream |
|---|---|---|
| Inter | UI workhorse | https://github.com/google/fonts/tree/main/ofl/inter |
| JetBrains Mono | code/data | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |
| Space Grotesk | tech display | https://github.com/google/fonts/tree/main/ofl/spacegrotesk |
| Fraunces | expressive serif | https://github.com/google/fonts/tree/main/ofl/fraunces |
| Bricolage Grotesque | poster sans | https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque |
| Manrope | product UI | https://github.com/google/fonts/tree/main/ofl/manrope |
| Outfit | geometric display | https://github.com/google/fonts/tree/main/ofl/outfit |
| Instrument Serif | editorial serif | https://github.com/google/fonts/tree/main/ofl/instrumentserif |
| Libre Franklin | American grotesque | https://github.com/google/fonts/tree/main/ofl/librefranklin |
| Sora | futuristic sans | https://github.com/google/fonts/tree/main/ofl/sora |
| Archivo | wide grotesque | https://github.com/google/fonts/tree/main/ofl/archivo |
| DM Sans | friendly UI | https://github.com/google/fonts/tree/main/ofl/dmsans |

Install on Arch: copy the TTF files into `~/.local/share/fonts/design/` and run `fc-cache -f`.
