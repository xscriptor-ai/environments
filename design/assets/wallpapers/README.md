# Wallpapers

Intentionally empty. This pack contains the design system, references
and pipeline to produce wallpapers, not a wallpaper collection.

When a brief exists, output into:

```text
assets/wallpapers/ready/4k/
assets/wallpapers/ready/mobile/
assets/wallpapers/ready/ultrawide/
assets/wallpapers/demo-mobile-to-desktop/
assets/wallpapers/animated/
```

Record source, license, recipe and dimensions in `manifest.json` and
`ATTRIBUTION.md`.
