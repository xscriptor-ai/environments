# Design licensing

An asset without a clear license is a risk. Record source, author, license,
changes and date for everything.

## License matrix

| License | Commercial | Modify | Share-alike | Attribution |
|---|---|---|---|---|
| CC0 / Public Domain | yes | yes | no | not required |
| CC BY | yes | yes | no | required |
| CC BY-SA | yes | yes | yes | required |
| CC BY-ND | yes | no distribution of modified | no | required |
| CC BY-NC | no | yes | no | required |
| Unsplash License | yes | yes | no | appreciated |
| Pexels License | yes | yes | no | not required |
| Pixabay License | yes | yes | no | not required |
| OFL 1.1 | yes | yes | no | preserve license |
| MIT/ISC/BSD | yes | yes | no | preserve notice |
| Apache-2.0 | yes | yes | no | preserve notice/changes |
| GPL/AGPL | yes | yes | copyleft on distribution | preserve license |

## Rules

- CC BY-SA derivatives may need the same license; check before mixing with
  proprietary client work.
- CC BY-ND: avoid modifying (cropping/resizing may count).
- CC BY-NC: excludes client work and monetized channels.
- Unsplash/Pexels/Pixabay: no selling unmodified copies, no implied endorsement;
  terms change, verify.
- OFL: fonts can be embedded/used commercially; do not sell the font alone;
  preserve the license; modified versions may need a new name if reserved.
- GPL/AGPL: using a GPL tool to make output does not normally license the
  output; distributing a modified GPL program does trigger copyleft.
- People, private property, trademarks and street art have separate rights.
- AI: check model, checkpoint and service terms; record prompt/seed/model;
  avoid real people/brands/characters without rights.

## Attribution template

```text
“Title” by Author (Year).
Source: URL
License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
Changes: cropped, extended canvas, color graded, grain added.
```

## Provenance hygiene

1. Download from the original source.
2. Verify the license on the file page.
3. Save the license text/screenshot.
4. Record author, URL and date.
5. Keep the original.
6. Embed credit with ExifTool when appropriate.
7. Re-check before shipping.
